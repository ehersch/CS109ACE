## View the website locally

Open `index.html` in your browser. The website is plain HTML and CSS, with no install, build step, or ChatGPT account required. Keep `styles.css` and `CS_109A_Syllabus.pdf` alongside `index.html`.

GitHub renders this `README.md` on the repository homepage. To serve the styled HTML website, use GitHub Pages:

1. Push these files to the repository’s `main` branch.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, then **main** and **/ (root)**, and save.

After GitHub Pages is enabled and deployment completes, the expected address is `https://ehersch.github.io/CS109ACE/`.

Edit `index.html` for the website content and `styles.css` for its appearance. Keep the schedule and course information in this README in sync when updating them.
